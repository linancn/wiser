# Security policy

Agent EXCON is pre-1.0 software. Do not expose its local Supabase stack or development defaults to the public internet.

Report suspected vulnerabilities privately to the maintainers rather than opening a public issue. Until a dedicated security address is published, use a private repository advisory when the project is hosted on GitHub.

Never attach credentials, participant data, hidden outcomes, or production logs to a report. The project does not accept committed ChatGPT/Codex authentication files, Supabase service-role keys, database passwords, or API tokens.

Security fixes should include a regression test whenever disclosure risk permits.
