## Documentation boundary

This site describes the systems that run now. Commands, ports, and source entrypoints must be verifiable from the repository. Manifests, the lockfile, and container-version records are authoritative for versions. Planning notes, milestone recaps, and design processes superseded by the implementation do not belong in operational guidance.
