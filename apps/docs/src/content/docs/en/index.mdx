## Reading current status

Available web actions follow the current account, project, and data permission. Ingestion or parsing does not mean publication or scientific suitability; execution traces do not change exercise evaluation. See the [data access and integration guide](/en/development/wiser-data-guide/) for the public external-client protocol and personal-client acceptance boundary.

Local commands and protocol details describe the runnable repository. Each guide distinguishes supported paths from those needing further authorization or acceptance. Package manifests, the lockfile, and container configuration are authoritative for dependency versions.
