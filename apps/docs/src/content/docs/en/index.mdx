## Two running systems, one platform boundary

<Cards>
  <Card title="Environment control">
    Pin scenario versions and virtual time, then release observations without
    hindsight leakage.
  </Card>
  <Card title="Fact-based adjudication">
    Deterministic rules come first; statistical, model, and human evaluators
    retain evidence and versions.
  </Card>
  <Card title="Open protocols">
    HTTP is the foundation. Each system derives REST, GraphQL, MCP, and Skills
    from its own strict Zod Capability or protocol contract.
  </Card>
  <Card title="Multi-agent collaboration">
    Roles execute parallel Tasks, converge through explicit artifacts, and
    receive distinct individual, role, and team feedback.
  </Card>
  <Card title="Historical-perspective replay">
    Events and Agent receipts reconstruct what each member actually received;
    OTel traces diagnose technology but do not define audit truth.
  </Card>
  <Card title="Data Foundation">
    Upload, quarantine, scan, interpretation, deterministic transformation,
    quality review, authority versions, and five rebuildable projections form
    one verified slice.
  </Card>
  <Card title="Unified identity and UI">
    Both systems share Supabase Auth, the WISER shell, Chinese/English,
    light/dark themes, and one Fumadocs site.
  </Card>
</Cards>
