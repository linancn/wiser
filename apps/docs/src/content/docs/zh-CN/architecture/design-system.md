## 设计方向

WISER 面向水系统专家、导调人员和数据治理人员。界面的单一工作是：让使用者快速辨认权威事实、当前状态、风险、证据和下一步操作。

现有 Agent EXCON 的“水系统仪表台”视觉成为全 WISER 的设计基线。它不是通用 SaaS 面板：深水色表达权威与深度，河道青色表达流动关系，水位尺琥珀表达注意和人工门禁，等深线与流线只在一个签名背景层出现。所有新增系统沿用这一语言，不再另造品牌皮肤。

## 设计 Token

核心色来自当前 Web：

| 名称       | 基准色    | 用途                         |
| ---------- | --------- | ---------------------------- |
| Abyss      | `#071a21` | 深色画布、强信息区           |
| Channel    | `#0b303a` | 深色抬升面与渠道关系         |
| River      | `#087f8c` | 主交互、选中、流动关系       |
| Ripple     | `#5cc7d2` | 深色主题高亮与焦点           |
| Gauge      | `#dfa33e` | 注意、人工门禁、时间敏感状态 |
| Floodplain | `#edf5f6` | 浅色画布                     |

组件只能消费语义 Token：`canvas`、`surface`、`text-*`、`accent-*`、`success-*`、`warning-*`、`danger-*`、`border-*`、`shadow-*`。禁止在系统页面内部写新的品牌色或用颜色替代文字状态。

浅色与深色必须是同一信息层级的两种映射，而不是两个设计。主题使用 `wiser-theme` 持久化，首次访问尊重系统偏好，初始化脚本在 React hydration 前设置 `data-theme`，避免闪烁。

## 字体与信息层级

- Display：`Iowan Old Style` / 思源宋体一类克制的衬线字，只用于产品论点、页面主标题和重大阶段。
- Body：IBM Plex Sans / Noto Sans SC / 系统无衬线，用于任务、说明和操作。
- Utility：IBM Plex Mono / 系统等宽，用于 ID、时间、版本、哈希、指标和协议字段。
- 正文基准至少 16px，行高约 1.55；不能为了密度牺牲可读性。
- 中文是默认表达，协议字段保留英文；英文页面保持相同信息、路由、操作和状态。

## 布局合同

```text
┌ WISER Portal ─ 数据基座 ─ 智能体演练场 ─ Account ─ Theme ─ Language ┐
├ 当前系统工作区导航（Portal / Auth 不显示）──────────────────────────┤
│                                                    │
│ page thesis + authority/status strip              │
│                                                    │
│ primary workspace                                 │
│ evidence / operations / diagnostics               │
│                                                    │
└ source, authority, version, freshness ─────────────┘
```

- 信息层级固定为 `Portal → 业务系统 → 系统工作区 → 领域对象`；对象内页签不得提升为平台导航。
- WISER Logo 返回当前语言 Portal；Portal 不作为第三个系统。数据基座排在智能体演练场之前。
- 全局 Shell、系统切换、Project 上下文、主题和语言在所有页面位置一致；系统工作区导航只在进入该系统后出现。
- 页面先说明用户面对的对象和当前权威状态，再展示指标或技术细节。
- 列表、目录和运行态使用相同的卡片、表格、过滤、分页、空态和错误态原语。
- 技术诊断可以更密，但不得污染管理和业务页面的第一视觉层。
- 宽屏最大内容宽度、窄屏 390px、键盘导航和 reduced-motion 都是强制验收面。

## 状态与组件

统一组件至少包括：AppShell、SystemSwitcher、ProjectSwitcher、PageHeader、AuthorityStrip、StatusBadge、MetricCell、DataTable、FilterBar、EmptyState、FailureState、OperationTimeline、EvidenceLink、VersionPicker、ThemeToggle 和 LocaleSwitcher。

- 成功、警告、失败、等待与未知状态同时使用文字、形状和颜色。
- 按钮使用动作动词；同一动作从按钮到 Toast 保持同名。
- 空态解释可以做什么；失败态说明发生了什么、影响范围和恢复动作。
- 所有可见文案必须同时进入 zh-CN 与 en 字典，禁止组件内散落硬编码双语三元表达。

## 产品内容边界

- 普通页面先说明用户目标、当前状态、影响和下一步，不解释实现架构。
- 页面导语、空态与失败态不得显示环境变量、内部 URL、HTTP 状态、原始错误码、DTO/DAL、数据库、Worker 或运维恢复命令。
- Trace、Span、CRS、版本和哈希等术语只在完成专业任务确实需要时出现。
- 详细的命名、公开入口、文案与新系统接入合同见[产品界面与内容设计](/development/product-experience/)。

## 系统适配

- Agent EXCON 的签名对象是 Run、Receipt、Barrier 和协作流线。
- Data Foundation 的签名对象是 DataItem、Version、Ingestion、Operation、Lineage 和地图图层。
- 两者共享 Shell、Token 和组件，但不伪装领域术语：同一种视觉状态可以承载不同领域对象。
- 地图、Trace、血缘图等高复杂度视图可以拥有专用画布，但主题、焦点、面板、图例和状态语义仍来自共享系统。

Data 地图把这一合同落实为可访问控件，而不是只靠画布颜色：DataItem 版本链接使用 `aria-current`，地图表单同时固定 bbox、不可变 Version 与 EPSG:4326/4490 source CRS；PostGIS authority、STAC extent、vector MVT、raster 四图层都用带文字的 checkbox，缺失图层保持 disabled。控制区持续显示 selectedVersion 与 显示坐标转换及位置尚待独立核对状态，图层颜色从当前主题 token 读取，深浅色切换不改变权威层级。浏览器瓦片使用同源 Web 路径，服务器身份与内部 GIS origin 不出现在 UI。

只有栅格的专业地图在缺少已验证要素和 STAC 范围时，按查询区域设置初始视角。缺失图层的提示仍然保留，不将视角位置展示为新增、已验证的空间要素。

探索地图的范围操作与视口计数位于画布上方的正常文档流。底图加载和失败提示保留在画布内，避免遮挡“适合范围”和范围筛选，同时保留底图重试。

## 验收

每个页面必须通过中文与英文、浅色与深色、桌面与 390px、键盘焦点、无浏览器错误、无横向溢出和 reduced-motion 检查。截图评审同时比较 EXCON 与 Data Foundation，任何看起来像第二套产品的局部 UI 都需要回收到共享 Token 或组件。

### 数据探索工作区

数据工作区采用紧凑标题并约束网格子项，使真实长摘要和标识符在窄屏内换行。图谱画布使用共享语义色、可读文本替代视图和带版本来源的选择详情。选中节点同时用轮廓与颜色表达，实体列表按钮支持键盘选择。

`/[locale]/data-foundation/explore` 工作区与 API 共享严格探索契约。紧凑查询栏、资源表格与选择详情面板将结果区置于页面上方。服务端渲染建立或恢复授权结果集，后续请求经过验证当前 Session 的 Next.js 入口 `/api/data-foundation/explore`。调整筛选建立新版本清单，分页沿用同一 `queryId`。数据名称支持键盘操作，详情显示精确版本、就绪状态及来源限制；未知分析数量不会显示为零。

探索工作区的资源、记录、地图页签共用查询栏和一个详情面板。页签支持方向键、Home、End。视图间使用相同记录标识，切换结果集清除选择并忽略旧查询事件。地图图层使用语义主题色，表格在自身面板内滚动。

共享详情面板也接受有明确类型的图谱节点。G6 溯源视图使用有界分层布局和可通过键盘操作的节点列表；聚焦记录切换到地图或表格时保留相同身份。查看节点时保持进入图谱时的范围，通过明确的全图操作返回整个查询的关系图。

数据探索将提供机构、登记类型和就绪状态放在可展开的筛选区。紧凑的覆盖说明汇总整个结果集，并用文字区分内容与空间状态；完成检查不等于已有可用内容，汇总不以当前页条数代替结果总数。

探索工作区的统计页签按需加载 [Apache ECharts 6.1.0](https://github.com/apache/echarts/releases/tag/6.1.0)，使用 SVG 渲染和所需图表组件，展示服务端计算的完整授权查询就绪状态数量。选择图柱或对应的键盘可用文字按钮，将同一状态条件应用到资源探索。图表颜色遵循语义变量；卸载时释放尺寸/主题观察器和图表实例。资源数量不能表述为记录数或科学观测数。

探索契约 1.5 增加可选的地图整体 `spatial.bounds`（WGS84；空结果为 null）及 `mercatorFeatureCount`，由同一授权记录集合计算，不受分页影响。浏览器只请求一条初始记录与范围摘要，定位整个结果范围，再按视口加载同源查询瓦片。点选单要素通过 1.4 的精确记录回查获取详情，点选聚合点继续放大。地图分别标明视口要素／聚合点数与可上图记录总数。追加迁移 `0015_exploration_tile_boundaries.sql` 明确接缝点的唯一瓦片归属，防止重复计数。1.4 契约仍保留在归档中。

当响应表明授权或固定成员范围失效，或结果到达声明的过期时间时，探索工作区一并清除当前查询、选择、文件详情及已渲染视图；从后台或历史页面恢复时再次检查同一截止时间。旧查询的迟到失败不能清除新查询，被中止的请求也不能恢复旧数据。查询表单条件保留，便于重新获取当前有权查看的结果。临时地图故障卸载画布并提供重新加载，不展示上游诊断。

记录探索提供可展开的条件表单，支持最多八个类型明确的比较条件、标量排序及可选的 1–32 列配置。文本编号保留前导零；空白或非有限数值不能作为数值条件提交。应用条件会创建新的单版本／文件授权查询、清除选择、新增历史记录并打开记录视图；记录、地图瓦片和记录溯源使用同一谓词。刷新后从授权查询恢复配置，清除条件则恢复该版本的记录浏览。数值比较使用来源值，不推断或换算单位。

选择资源后，统计视图提供来源记录聚合，字段控件与资源就绪状态计数分开表达。图表配有精确值表格及可通过键盘操作的分组选择。单位明确显示，未知分组不会被悄悄替换成不完整的空值条件。

图谱探索提供键盘可用的文件、证据和记录展开、邻居分页、带文字的关系开关，以及限定当前页的有向路径控件。路径高亮更新 G6 节点／边状态，不替换画布。两种语言均显示计数单位、截断状态与恢复操作；切换焦点会清除路径端点和游标。

探索工作区默认保存有名称的私人视图，支持明确选择项目分享、持久链接和创建者撤销。保存链接恢复经授权的固定查询、记录／图谱分页、所选来源、地图图层／视角及已应用的聚合配置；每次打开都会重新授权并建立新查询。导出下载一次有界 JSON 结果页，保留来源原值、准确返回／总量及完整／部分标记；地图初始记录页不代表全部已加载瓦片。尚未应用的草稿条件不会保存。

数据工作区导航将检索、知识和专业空间／图谱工具归入数据探索，原有深链接继续有效，探索工具栏提供专业入口。窄屏下只有资源表可以隐藏提供机构列；记录与聚合表在自身滚动区域内保留全部所选字段和单位。来源统计将资源就绪概况放入独立折叠区，仅在展开时挂载图表。来源层级图谱宽度小于 560 像素时由 Worker 计算纵向布局，并提供键盘可用的缩放、全图及所选节点定位控件；视角操作不使用动画。

宽度不超过 900 像素时，可通过底部按钮在非模态抽屉中查看所选来源。展开后键盘焦点进入带名称的详情区域；收起或 Escape 将焦点返回按钮，保留当前选择。取消选择时按需将焦点返回当前视图页签。桌面详情仍在侧栏中滚动。G6 内部画布图层不参与 Tab 顺序，键盘交互由有名称的视角控件和来源节点列表提供。

总览任务卡片进入统一数据探索工作区及其地图视图，并用面向用户的语言描述数据接入与审核。文档站按数据基座、智能体演练场的顺序介绍业务系统，与 Portal 保持一致。

图谱选择与路径更新只向 G6 提交状态发生变化的节点和边。取消路径时清除原有路径高亮并保留当前选择，避免每次选择都提交全图状态。大图首次绘制仍有有界的渲染开销；布局计算继续在可取消的 Worker 中完成。

Portal 根据已验证会话选择主操作：已登录用户进入数据工作区，匿名用户进入登录页。数据目录使用每页 25 行的游标分页及可键盘聚焦的内部滚动表格，后续页和返回第一页均保留名称条件。列表保留来源、发布、质量和安全信息，并引导结合详情中的检查范围与内容就绪状态判断。

数据发现与质量页面使用统一的紧凑标题和项目范围标签。目录与质量表格的状态标签保持单行，内容按阅读方向对齐，表格在可键盘聚焦的区域内滚动；质量列表使用每页 25 条游标分页。综合和知识检索每页 10 条，在有界结果区提供名称与精确版本链接、短摘录，以及可展开的来源限制、原始摘录和证据详情。登记清单标记为来源登记，不作为文章正文展示。版本、接入和智能体接入页共用详情披露组件，使协议字段处于次要层级。

知识图谱画布默认使用使用确定性初始位置、最多 160 次迭代的 ForceAtlas2 关系网络，由现有可取消 Worker 计算。键盘可操作的布局切换提供 Dagre 来源层级；只有层级布局在窄屏改变方向。两种布局均保留有界身份、选择、路径高亮和文字替代视图，独立资源的关联组在二维平面分区排布。初始概览每页显示八项资源，聚焦后的邻居页保留独立条数上限。关系文字与语义节点颜色辅助表达节点类型。

资源页先展示内容工作区，治理信息位于可展开区域。版本内文件列表、原文件下载与内容页签共用精确资源身份。表格保留来源标量值，并为已知字段提供易读标签；文档与结构化视图按需展开嵌套内容。文件预览不执行来源脚本，暂不支持的格式保留明确下载操作。探索中的资源名称直接打开内容，另设选择控件以保留当前查询内的分析操作。

有可路由栅格源时，进入地图即显示像元，并与资产范围框分别标注。可用键盘操作的不透明度滑块只更新现有图层，不重建来源、不重置相机。透明区域不能解释为数值零；单位与数值范围仍需回查来源说明。

业务关系可加入最多六十三份带版本的平台资料链接。待审图需明确选择显示并持续标明待审。节点保留来源身份或明确引用身份。每条关系显示来源、原文、记录性质、时间与位置角色及适用条件。来源空间入口不表示已有或已核验几何。

业务关系深链接自动展开对应区域，恢复来源范围、审核状态与所选对象。累计图谱分别显示已加载条数和有权限的总数，并明确继续加载的上限；画布的全图按钮只调整视角。恢复待审预览后仍持续显示待审状态。

已加载业务图中的来源记录和空间入口保留经过校验的返回信息，仅含版本身份、审核状态、聚焦对象和加载页数。探索页面改写查询地址及切换标签时保留该信息，并提供返回刚才业务关系图的入口。它表示导航来处，不声称后续每次查询的范围都相同。返回地址仅由内部资料路由生成，不授予访问权，重新打开时仍核验权限；损坏信息不生成返回入口。加载范围外的引用资料保留普通来源链接。这不表示位置已核实或不同来源已具有相同空间范围。

业务关系可按对象类型与时间筛选已加载且有权限的关系。类型匹配任一端，时间含义精确匹配。日期按原资料明确时段是否重叠判断；仅有年、月时保留原粒度，不补猜具体日期。缺失、不完整、倒置或无法识别的时段保持未知；只有明确标为观测时间的记录才可使用单一观测时间。保留未知时段的选项作用于类型及时间含义选择后的日期筛选。图谱与证据列表共用同一子集，分别显示匹配、加载与总关系数；继续加载保留此前不匹配的行，清除条件后能够恢复。严格校验的筛选状态随链接、刷新、历史及来源探索返回而恢复；不扩展权限，也不宣称来源地图与记录查询已采用相同时间条件。节点标签含本地化类型，保持各来源身份。

精确记录探索链接通过有界的`recordFocus`仅保存资源、不可变版本和记录标识。打开或历史恢复时重新鉴权，并通过既有HTTP探索接口读取该条记录；返回的三个身份必须全部一致。记录缺失、参数错误、无权访问或身份不符时明确失败，不替换成首行或放宽到整份资料。地图/表格选中与视图切换保留定位及已校验的业务图返回上下文；应用新查询条件或选择其他资源时清除旧定位。选中记录不代表坐标已经核验，也不自动建立科学对象身份或图谱到空间要素的映射，这些仍须来源证据支持。保存视图继续遵守原有选中契约，不与独立记录定位混用。

观测记录节点可用`urn:wiser:record:<recordId>`声明平台记录标识，范围限定在自身来源版本或显式引用来源。网页只对OBSERVATION节点的合法UUID绑定提供精确记录与空间内容链接，不从名称猜记录，也不给文档虚设几何。链接保留原业务图返回状态，打开时重新鉴权并核对完整记录身份。此标识是导航声明，不代表服务端已认定科学身份或通过专业审核；证据和待审状态仍保留。其他外部标识不受影响。

### 精确关系历史导航

查看更正前关系时，将明确的关系ID写入来源绑定的链接。刷新和浏览器历史恢复后重新鉴权读取该条关系，并核对来源版本与审核状态；目标无效、不可读或状态已变化时失败，不替换成其他行。历史查看清除图节点聚焦和日期筛选，保留可授权核查的案例范围，不执行关系审核或替代。

精确记录入口在没有已保存分页视图时直接请求所选记录，跨页记录也须立即可见；返回身份不符时失败，不替换第一页。用户可“浏览本文件记录”回到同一查询条件下的文件分页，清除链接中的精确定位并保留业务图返回上下文。已有保存视图优先保留其页码和游标。

记录检查区通过已授权的分页业务关系列表反查明确记录绑定，沿用有效案例来源和关系筛选。没有案例时默认仅查当前版本已通过关系，待审范围须明确选择。部分完成、无绑定和读取失败分别显示；拒绝访问时清空结果。点击匹配项进入来源限定的业务节点，原图返回入口独立保留。切换记录中止并清空此前查询，不按名称或虚构几何匹配。

业务图链接可保存`revisionMode: "all" | "current"`；未指定时显示全部历史。当前记录仅在完整、未聚焦的范围载入后，收起同一资料、同一三元组、同一已通过或待审队列内有明确更正指向的前版。不按时间戳猜最新，不替用户解决并行分支，不让待审更正覆盖已通过知识。分页未完、局部对象和精确历史保留全部已载入记录并说明范围；循环或无效指向不隐藏证据。类型与时间筛选在更正选择之后应用，前版仍可精确回查。这是授权查询结果的显示选择，不产生新的审批或权威状态。

保存查询含业务条件时，探索页打开多源问题与证据图。默认全景包含全部已授权观测明细并显示完整图中/范围计数，选择对象可展开依据且保留完整网络。记录与地图链接保留同一查询，审核状态持续可见；普通查询仍保留资料来源图。中英文使用共享图画布和设计变量。

图谱在适配、缩放和拖动后，按当前元素位置预留屏幕文字范围；隐藏标签不绘制文字，连线保持可辨认宽度，重叠时优先保留所选对象和总览标签，放大后逐步显示更多名称。此处理不减少节点、关系或查询范围，不改变计数；完整对象仍可通过键盘列表与证据区访问。

业务图对象列表用当前已授权关系中的资料名称区分同名对象；选中对象可进入其自身的准确来源版本，跨资料引用也按被引用身份定位。名称缺失时显示资料编号，同一资料内仍重名的对象保留各自编号。此说明不合并身份、不补造关系、不扩大查询范围。

业务探索提供按需展开的关系路径阅读：选择两个来源明确的对象，在当前完整授权关系中查看最多八步的一条最短连接及逐条原文。阅读时可以从关系任一端寻找联系，但保留原始关系方向，不推断因果、审核结论或新关系。这是本页局部图形阅读，不改变记录和地图的共用查询；修改起终点即清除原路径。

关系详情、查询结果和联系路径中的证据链接，应打开该证据实际所属的固定版本，同时保留当前关系的上下文。引用另一份资料时改变的是原文跳转目标，不能把外部文件误标为当前文档的文件。

探索地图的位置说明放在画布下方的正常文档流中，不覆盖图层图例或错误恢复按钮。中英文窄屏、宽屏分别检查展开图例和重试状态；布局可见性与地图位置正确性分开验收。

嵌套来源字段按所在单元格的可用宽度排列名称与值。即使在桌面端，窄单元格也将名称置于值上方，避免展开表格证据后将短数值挤成逐字换行。原值与证据选择保持不变，滚动仍由外层表格承接。

可选分组阅读每组显示六条真实关系。圆角文字节点按层次排列，并为卡片完整尺寸预留间距；文字保持水平。共享端点处重复的关系名称可显式开启或通过选中对象查看，独立对象对仍显示关系名称。完整网络入口与全部已授权对象的键盘查找保留。阅读控件位于独立工具栏，不遮挡画布；图与证据列表展示同一组，并分别显示当前范围与查询计数。

### 业务图谱查阅与呈现

业务问题图在全景总览、资料对照、围绕对象、证据追溯、时空对照五种查阅视角及平面、类别立体分层、空间锚点三种呈现方式之间保留完整授权关系集合。显示设置和有界视口参数保存在网址中，同一查询的记录／地图链接保留这些参数与准确的选中关系。资料对照分列来源类别和业务内容；一层／两层邻域保留原断言方向，证据视角展开既有有界路径阅读器。按来源标题归类是明确标示的阅读辅助，未知分类保持未知，不改变来源登记、身份或知识审核。时间组织只采用对象自身来源中明确的观测／事件时间含义，未知与多时段对象单列。

业务画布使用确定性分类位置和 SVG 立体投影；普通来源图及可选的六条断言分组阅读继续使用 G6。立体层标题放入独立侧边标注区，通过引线连接图层。滚轮、双指和键盘缩放只改变视口，不重排节点或删除连线，名称随尺度逐步出现；所选对象、关系与证据也可通过键盘列表访问。悬停预览直接联系，点击锁定依据并淡化完整网络背景。交叉连线命中时列出实际候选断言供选择。证据区保留原始支持／矛盾含义、准确来源版本、表格／段落定位、限制、审核状态和前版关系入口。

空间呈现复用完整有界的 HTTP 地图查询，按资料、版本、记录三个标识绑定原始点线面几何，沿用既有显示坐标转换；无位置知识单列并保留原关系。虚线将资料标签连接到原几何的显示中心，标签和中心均不成为新增点要素或业务关系。位置读取拒绝范围不符、分页不完整及无权结果。移动地图不改变业务问题；位置精度与知识审核保持独立。画布操作不下载原件、不重跑解析、不迁移数据库、不写入业务数据。

工作区全屏沿用语义背景、具名对话区域和固定可见的退出按钮，原组件保留阅读状态。全屏期间限制键盘焦点在工作区内，退出时恢复焦点，不改变查询成员。搜索解释与示例保持次要层级，在窄屏内换行。

节点颜色与形状固定编码业务类别；边颜色编码谓词家族，虚线只表达待审，身份对应不附单向箭头。全景/证据/流畅读图风格只改变标签显示，保留全部对象和关系，并通过已有URL视图状态恢复。

分组标题按可用画布范围避让，并以无箭头引线指向原分组。拥挤时只减少标题，明确显示已展示标题数；完整分组和成员仍可从键盘列表访问。标题排布不改变业务对象、关系或空间坐标。

空间锚点与平面图谱沿用同一套节点类别、形状、关系颜色、待审虚线和无箭头身份关系。未定位成员在各自分组中确定性排布，按成员数量分配空间，不把所有组挤入固定半径小圆。全部成员和关系保持不变；画布排布不产生地理位置或新身份。

空间图谱定位线、面或多部分对象时，在未被资料区遮挡的地图范围内显示完整几何范围；仅零范围几何使用点位聚焦。显示中心只作标签连接，不生成采样点；尚未绑定获准几何的地名保留既有关系，不猜坐标。

空间覆盖分列具有准确记录绑定的来源内对象，以及去重后的点、线、面和混合几何。同一记录被多个知识对象绑定时几何只计一次，多部分几何仍计一个要素；有名称但未绑定范围的地点、河段、流域和监测点另计，保留各自身份。只有完整授权地图结果读取成功后才显示计数，加载中或无权时不显示为零。上述数字不代表全部资料的空间解析召回率、不同真实地点数或专业核验结果。

平移通过保留的SVG分组上的CSS变换完成，同时保留等价SVG属性作为回退，不重建或删除成员。滚轮运动和实际拖动期间，暂不把经过鼠标的对象当作悬停查阅；已经选中的对象和证据保留，滚轮停下后恢复主动悬停。平面与分层视图都需核验移动后的实际点选位置。这些局部改动不代表缩放或大图性能已经达标，各种交互分别记录。

点选对象或关系时先把待保存的滚轮／平移视野写入网址，再更新选择；立即点选不应丢失最新阅读位置，也不能由迟到的视野写入覆盖选择。

业务图谱分页在响应到达及正文解析后均检查取消状态。已被替换的查询不能再通知当前视图失效或请求下一页；当前查询在后续页被拒绝时仍须失效，不能展示残缺图谱。

跳转资料原文时，官方底图须在地图容器移除之前释放实例和观察器。原文往返应恢复所选关系与地图视野，且不产生地图绘制错误；释放顺序不改变几何或授权。

项目业务图谱按服务端固定关系清单的数量控制分页，旧式查询保持原有上限。筛选后的关系数可以少于固定成员数；总数矛盾、重复关系或分页不完整时，不展示为完整全景。应用业务时段须基于原查询编号细化，后来新增的资料或关系不会悄悄进入图谱、记录或地图。

探索查询失效时，同时取消仍在途的替换请求并结束加载状态。迟到的成功响应不能在过期或权限失败后恢复资料；用户须显式重新查询。

混合审核查询显示“已审与待审”，每条关系仍保留各自状态与候选标识。混合范围不构成审核操作；记录返回图谱沿用同一授权查询，不切换成仅已审列表。

数据基座正常入口和无条件探索入口打开当前授权项目业务图，紧凑标题与保存专题、资料搜索分别标识；已审与待审关系保留各自标签。保存专题仅在展开时加载。运行状态作为次级内容，不以示例数据替代业务图。

点击空间点、河线或区域面时，按当前授权查询中的来源、版本、记录绑定列出全部命中对象；重叠对象由用户选择，重复图层命中去重但不合并来源身份。关联资料面板按类别组织已有关系，点选打开原断言及原文依据。仅允许经过一条明确限定的空间参考身份对应边读取另一来源内区域的相邻证据，并标明间接参考关系。选择保留地图位置与查询时段，不把同名推定为空间绑定。

已选择的地图对象以有界的来源内身份保存在网址中，与所选证据关系分开。刷新或原文返回时，只有当前授权地图结果仍提供精确记录绑定，才恢复关联资料面板；不可用对象不会按同名替换。返回未定位资料列表会清除该阅读选择。网址不保存几何或原文，也不授予数据访问权限。

细河线和点允许六个屏幕像素的点击容差，仅查询已经绘制且获准的几何图层。区域面仍采用实际命中；重叠候选全部列出，未知绑定丢弃。这一操作容差不扩大地理范围、不改变资料位置、不生成关系，也不移动地图。

业务记录目录与图谱共用服务端成员清单上限，支持超过旧式2,000条关系上限的项目查询。仅在完整分页通过后展示记录链接；超出成员范围、空续页、计数矛盾和重复关系均明确失败。被替换的查询在响应或正文到达后立即停止，不能再请求下一页或使当前查询失效。资料、版本、记录绑定保持精确。

数据探索将重复介绍、图谱范围说明、读图风格含义和地图参考范围解释收进既有圆形问号帮助。悬停展开，点击或键盘激活可固定，Escape关闭。查询计数、审核/权限/失败状态和资料自身证据仍在相关位置显示；可选帮助不替代当前状态警告，中英文原说明均保留。

全屏工作区内，打开问号说明后按Escape先关闭该说明，再次Escape才按原规则退出全屏，不清除图谱选择。

问号按钮不受工作区普通按钮样式挤压，保持圆形；粗指针设备使用较大点击目标，说明弹层在打开和窗口缩放时限制在视口内。
