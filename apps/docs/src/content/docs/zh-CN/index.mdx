## 文档边界

本文档站描述当前可运行系统。命令、端口和代码入口必须能从仓库直接验证；版本号以 manifest、lockfile 与容器版本登记为准。规划、里程碑复盘和已经被当前实现取代的设计过程不属于运行手册。
