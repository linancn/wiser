## 一个多智能体环境，而不是一组演示接口

<Cards>
  <Card title="环境控制">
    锁定场景版本和虚拟时间，按规则释放观察，避免历史回放中的时间穿越。
  </Card>
  <Card title="事实裁决">
    确定性规则优先；统计、模型和人工评价均保存依据、版本与置信度。
  </Card>
  <Card title="协议开放">
    HTTP 是统一底座，TypeScript SDK、文件化 Skill 和 MCP Server 都建立在同一份
    Zod 合约上。
  </Card>
  <Card title="多智能体协作">
    多个角色并行完成
    Task，以显式工件汇流成团队提交，并分别获得个人、角色和团队反馈。
  </Card>
  <Card title="当时视角回放">
    事件与 Agent Receipt 重建每个智能体实际获得的信息；OTel Trace
    用于技术诊断而非审计事实。
  </Card>
</Cards>
