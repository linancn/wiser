## 两个已运行系统，一套平台边界

<Cards>
  <Card title="环境控制">
    锁定场景版本和虚拟时间，按规则释放观察，避免历史回放中的时间穿越。
  </Card>
  <Card title="事实裁决">
    确定性规则优先；统计、模型和人工评价均保存依据、版本与置信度。
  </Card>
  <Card title="协议开放">
    HTTP 是统一底座；每个系统的 REST、GraphQL、MCP 和 Skill 都从自己的严格 Zod
    Capability/协议合约派生。
  </Card>
  <Card title="多智能体协作">
    多个角色并行完成
    Task，以显式工件汇流成团队提交，并分别获得个人、角色和团队反馈。
  </Card>
  <Card title="当时视角回放">
    事件与 Agent Receipt 重建每个智能体实际获得的信息；OTel Trace
    用于技术诊断而非审计事实。
  </Card>
  <Card title="数据基座">
    上传、隔离、扫描、解释、确定性转换、质量审核、权威版本与五类可重建投影形成一条可验证纵切。
  </Card>
  <Card title="统一身份与界面">
    两个系统共享 Supabase Auth、WISER Shell、中文/英文、浅色/深色主题与同一
    Fumadocs 文档站。
  </Card>
</Cards>
