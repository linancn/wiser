## 如何判断当前状态

网页可完成的操作以当前账户、项目及资料许可为准。资料完成接入或解析不代表已经发布，也不代表适合科学分析；演练追踪不改变评测结果。现网外部客户端的协议与本人客户端验收状态见[资料查阅与接入指南](/development/wiser-data-guide/)。

本地开发命令和协议细节以本仓库可运行实现为准。文档分别说明当前支持的路径和需要额外授权或验收的边界；依赖版本以项目清单、锁文件及容器配置为准。
